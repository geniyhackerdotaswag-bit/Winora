# Наборы курсоров, которые Winora предлагает скачать

Экран «Курсоры» читает `index.json` из этой папки по её адресу на `raw.githubusercontent.com`
и показывает карточку на каждую запись. Пока список пуст — карточек скачивания нет, и экран
показывает только наборы, лежащие у человека в `%USERPROFILE%\Winora\Cursors`.

## Как добавить набор

```json
{
  "packs": [
    {
      "id": "chroma-black-s",
      "name": "Chroma чёрная S",
      "author": "имя автора набора",
      "archiveUrl": "https://github.com/<владелец>/Winora/releases/download/cursors-v1/chroma-black-s.zip",
      "previewUrl": "https://raw.githubusercontent.com/<владелец>/Winora/main/assets/cursors/chroma-black-s.png",
      "sizeBytes": 640000
    }
  ]
}
```

- `id` — имя папки, в которую набор распакуется. Только имя: без косых черт, двоеточий и `..`.
  Каталог — файл из интернета, и он не выбирает, куда писать.
- `archiveUrl` — zip. Ассеты релиза подходят лучше, чем файлы в репозитории: у бинарников
  здесь не место, а история репозитория от них пухнет навсегда.
- `previewUrl` — обычный PNG. Показывается на карточке, пока набор не скачан: `.cur` и `.ani`
  WinUI рисовать не умеет, а нарисовать курсор можно только когда его файлы уже на диске.
- `sizeBytes` — чтобы карточка сказала размер до нажатия.

## Что попадает на машину

Из архива берутся **только** `.cur` и `.ani`, каждый по своему голому имени. Readme,
установочные скрипты, картинки и вложенные папки отбрасываются, а запись вида `..\..utorun.inf`
теряет путь вместе с попыткой выйти наружу. Программа работает с правами администратора, и это
единственная причина, по которой распаковка устроена именно так.

## Права на наборы

Курсоры делают люди, и у наборов бывают условия распространения. Прежде чем класть набор сюда,
проверьте, что автор разрешает выкладывать его дальше, и укажите его в `author`. Winora не
раздаёт чужую работу молча.
